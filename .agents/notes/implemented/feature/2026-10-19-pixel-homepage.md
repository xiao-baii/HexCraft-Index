# Agent Note: 像素帆船与简洁个人主页

Status: implemented

## Problem

原有首页以时钟、云朵、草地和海浪占据主要空间，项目入口位于首屏下方。用户希望采用 Owlbay 的暖白、细线、淡文字纹理与居中布局，并明确要求大标题仅保留 `xiao-baii`，帆船改为像素风。404 需要延续相同品牌与导航，避免访问失效链接时跳回另一套小岛视觉。

## Decision

首页使用 Home Astro 静态组件和 CSS Module，以像素帆船、站名和 GitHub 链接组成主要内容。config 仅保留 GitHub 与备案信息，不增加搜索、博客、语言或主题切换。

移除首页时钟与滚动显现脚本，让主要内容和导航在没有 JavaScript 时仍可使用。文字纹理仅作装饰，使用已有技术和项目关键词，对辅助技术隐藏，避免截获点击。页面使用暖白背景、黑色文字和砖红强调色，保留键盘焦点。

共享 sailboat.svg 用于首页、favicon 与 404。Layout 固定使用暖白 theme-color，只接收标题和描述，不保留旧绿色默认值或可选主题参数；favicon 使用像素图标缓存版本。

## 404 integration

首页与 404 通过内部 SiteFrame 复用导航、页脚和基础样式。首页正文保持原有呈现，404 采用纯暖白底、左对齐错误说明和放大的共享像素帆船。共享导航仅保留首页与 GitHub 入口，仅首页显示当前页标记；每个页面保留 id 为 main 的可聚焦主内容，供跳转入口使用。

404 文案为“找不到这一页”和“这个页面不存在，或已经搬到了别处。”，正文仅提供指向 / 的“返回首页”。不增加搜索、客户端脚本、自动跳转或线上路由配置。

## Navigation

共享导航采用左侧品牌、居中首页、右侧 GitHub 图标的三段布局，内容高 64px。桌面导航字号 16px，两侧等宽网格使首页链接不受品牌宽度影响。404 顶部使用全宽浅色分隔线，首页不显示该线。600px 及以下仍保持单行，左右留白 16px，导航字号 14px，首页链接至少 44×44px；完整品牌与 GitHub 占据两侧，首页链接在剩余空间中居中。

页脚只保留署名与备案链接，桌面分列左右，手机分两行左对齐。GitHub 已在顶部导航提供入口，页脚移除重复链接，首页内容区的 GitHub 保留。

顶部“项目”入口、中间指向当前页面的“主页”条目和 404 的“查看项目”均已移除。首页中间仅保留静态 GitHub 链接，没有项目配置、列表循环、页内定位锚点或额外目标高亮。

站名使用本地 xiao-baii.svg 像素字标，与现有帆船搭配；链接通过 aria-label 保留站名和 GitHub 的可访问名称，图形本身为装饰。字标使用整数倍缩放，不引入字体下载、客户端脚本、快捷键或新的配置字段，现有链接地址保持不变。

## Legacy cleanup

Home 组件与样式文件替代旧的小岛命名，GitHub 入口直接渲染外部链接，不再通过通用项目数组与内外链判断生成。保留当前尺寸、排版、文字纹理、悬停和键盘焦点；移除列表分隔线、锚点滚动边距、多按钮容器和单项导航中无效的间距规则。首页描述为“xiao-baii 的个人主页。”。

未使用的 animal-island-ui 及其 React 依赖从依赖树移除，锁文件同步更新；TypeScript 沿用 Astro 默认 JSX 设置，不保留 React 配置。Layout 只保留全局尺寸与边距重置，删除未使用的旧小岛主题变量。清理只覆盖当前站点，web 历史副本继续被排除，其他工作区和本地截图不删除。

## Verification tooling

仓库通过 npm run verify-notes 串行运行目录、格式与归档校验。四个源码复用自 write-notes-like-deepseek，使用已有 TypeScript 转译为等价的 JavaScript 后保存在 scripts/notes，不增加依赖，不引入看板或 CI 工作流。使用 JavaScript 是因为仓库未安装 Node 类型定义，直接引入工具的 TypeScript 源码会令 Astro 页面类型检查失败；校验器行为由实际执行和正反例检查验证。

## Alternatives considered

- 保留原有项目卡片与左右首屏，只调整配色：改动较小，也能保留原先的内容层次。但用户明确选择整体接近参考站，保留这些结构会继续让装饰与空白占据首屏，因此采用居中入口布局。
- 增加搜索框及快捷命令：能接近参考站的交互，并适应较多项目。但当前没有需要搜索的项目内容，用户明确选择直接链接入口，因此暂不增加搜索状态、索引或客户端脚本；内容增长且用户需要搜索时再评估。
- 换成像素小动物标识：更接近参考站的角色感。但用户选择像素帆船，因此延续帆船的辨识度并更新表现形式。
- 在 404 复制首页导航及页脚：单页改动更直接，也能避免移动首页代码。但两页现在需要长期保持相同品牌、导航与备案信息，因此提取仅包含这些已有内容的共享页框，不扩展为通用页面配置系统。
- 保留普通文字站名、只调整导航位置：代码更少，改名时也无需编辑图形。但普通粗体缺少参考站明确的像素字标特征，因此仅为固定站名制作静态 SVG，正文继续使用系统字体。
- 手机导航分两行：能给品牌与导航更多空间，也容得下更多入口。但用户要求所有入口保持同一行，因此缩小间距与字号，同时保留完整品牌和至少 44×44px 的导航点击区域。
- 为项目导航添加目标高亮与焦点定位：可以在无需滚动的短页面提供明确反馈。但用户选择直接移除重复的导航入口，因此不保留额外的列表状态。
- 保留空项目数组和旧 UI 依赖：以后恢复项目展示或旧风格时更方便。但当前只需要静态 GitHub 入口，保留这些结构会延续失效入口与编译配置，因此删除；有真实的新展示需求时再设计对应结构。

## Consequences

首页的个人标识与链接入口集中于首屏，核心内容无需客户端 JavaScript，帆船 SVG 可在导航、favicon 与 404 中复用。共享页框让导航、备案信息和品牌样式只需维护一处，但修改时需要回归两页。静态 GitHub 入口消除了空项目模型和无效导航；以后增加项目展示需要明确设计，不再通过旧配置自动扩展。正文使用系统字体保证本地可用，品牌字标使用本地 SVG，未来更改站名需要同时更新图形与可访问名称。手机单行导航节省纵向空间，但首页链接在品牌与 GitHub 之间居中，不与视口中心对齐；增加导航项或加长站名时需重新评估窄屏空间。固定暖白主题不提供页面级主题切换。校验器在仓库内保存副本，技能更新不会自动同步。
